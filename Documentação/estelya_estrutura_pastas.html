Backend por domínio

Cada módulo representa uma capacidade do negócio. Isso evita um projeto gigantesco dividido apenas em controller, service e repository.

⌘

n8n separado

Workflows versionados em JSON ficam fora do backend. O Spring Boot continua sendo o dono das regras críticas.

▣

PDV isolado

O PDV Web/PWA usa a API central. O agente local cuida de SQLite, impressão, TEF e contingência.

▤

Infraestrutura explícita

Docker, Nginx, PostgreSQL, Redis, object storage e monitoramento ficam versionados como infraestrutura do produto.

Regras arquiteturais

  • Frontend nunca acessa PostgreSQL diretamente.
  • n8n nunca altera tabelas diretamente.
  • PDV usa a API do Spring Boot.
  • Integrações externas ficam atrás de adapters/providers.
  • Multi-tenancy faz parte do núcleo de segurança.
  • Migrations de banco são versionadas com Flyway.
  • Segredos não entram no Git; somente .env.example.
